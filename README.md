# Fake Player Limit 假人数量限制

[![License](https://img.shields.io/github/license/Redlnn/FakePlayerLimit.svg)](http://www.gnu.org/licenses/lgpl-3.0.html)

A [Carpet mod](https://github.com/gnembon/fabric-carpet) (fabric-carpet)
extension used to limit the number of fake players that each player can spawn.

一个 [Carpet mod](https://github.com/gnembon/fabric-carpet)
(fabric-carpet) 的扩展，用于限制每个玩家可使用的假人数量

#### Compatibility Notice 兼容性提醒 

Tested to be compatible with
[Carpet-TIS-Addition](https://github.com/TISUnion/Carpet-TIS-Addition)'s
`fakePlayerNamePrefix` and `fakePlayerNameSuffix` rules.

经测试与 [Carpet-TIS-Addition](https://github.com/TISUnion/Carpet-TIS-Addition) 的
`fakePlayerNamePrefix (假人名称前缀)` 和 `fakePlayerNameSuffix (假人名称后缀)` 兼容
